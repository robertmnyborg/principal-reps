# Set up the Claude Project

This takes about five minutes. You need a Claude account. You do not need Claude Code.

1. Open claude.ai and go to Projects.
2. Select **Create project**. Name it `Principal Reps`.
3. Open the project settings and find the custom instructions field.
4. Copy the entire contents of `INSTRUCTIONS.md` into that field. Save it.
5. Open the project knowledge panel. Upload all three files from `knowledge/`.
6. Start a new chat in the project. Type `set 5`.

## Before your first rep

Turn on dictation. Answer out loud. A typed answer is not a scored rep, because you edit
while you type and a live room gives you no edits.

Start a timer for ninety seconds when the question appears. Report your elapsed time with
your answer.

## Sharing it

Share the project from the project menu. Anyone you share with gets the same setup with no
configuration.

## What this version does not do

This version has no ledger. Scores live in the chat and end with it. Progress across
sessions, spaced repetition on weak dimensions, and the graduation check need the Claude
Code plugin in the parent directory.
